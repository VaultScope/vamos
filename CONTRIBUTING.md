# Contributing to VaultScope

First off, thank you for considering contributing to VaultScope! It's people like you that make VaultScope such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our Issues tab first. If it's not there, feel free to open a new issue.

## Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Issue that pull request!

## Code Style

Please follow the standard formatting tools for the language (e.g., `cargo fmt` for Rust, `eslint`/`prettier` for TypeScript).
